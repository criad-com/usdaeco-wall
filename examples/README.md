# Wall examples

The [minimal stage](../usdAecoWall/examples/minimal.usda) has L/T joins,
a hosted opening and a three-layer catalog. It composes plugin-free using
stock fallback types. Its axes are guides, not body geometry.

The [data-centre example](datacentre/README.md) composes published Route K
bodies, promotes 92 walls and derives 19 office-wing axis guides. Its
expected zero topology counts reflect missing source records.
